# Marketing A/B Test — Campaign Effectiveness

## About the Project

For this project, I wanted to understand whether showing users digital advertisements could lead to more conversions than showing them a public service announcement (PSA).

The main goal was to compare both groups, explore the data, and see whether the advertising campaign performed better.

## What I Did

I started by exploring and cleaning the dataset to make sure it was ready for analysis. Then, I looked at the number of users in each group, compared their conversion rates, and explored patterns in when users saw the most ads.

I used Python to analyze the data and create visualizations, and Tableau to build an interactive dashboard that makes the results easier to understand.

To check whether the difference between the two groups was meaningful, I also performed a two-proportion z-test.

## Key Findings

The advertising group achieved a conversion rate of **2.55%**, compared with **1.79%** in the PSA group.

This represents a difference of approximately **0.77 percentage points**. The statistical test showed that this difference was statistically significant.

In other words, users in the advertising group converted at a higher rate in this dataset.

## Final Thoughts

The results suggest that the advertising campaign was more effective at generating conversions than the PSA in this experiment.

However, a higher conversion rate does not automatically mean a campaign is more profitable. To understand its real business impact, we would also need information about advertising costs and revenue.

## Tools Used

- Python and Pandas for data cleaning and analysis
- Matplotlib and Seaborn for data visualization
- Jupyter Notebook for the analysis
